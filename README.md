# Alarm-box
Lift the lid, an Alarm goes off.

I built this box for a science fair, and as a personal project for something fun.

Parts:

(1) DFRobot FIREBEETLE 2 ESP32-C6        

(2) SparkFun Ultrasonic distance sensor

(3) CQRobot-Enclosed-Speakers

(4) 3.7V 2000mAh 103450 1S LiPo Battery

(5) Omron B3F-1000 Tactile Switch

(6) ELEGOO 400-Point Solderless Breadboard 

(7) GPIO Wires

All parts can be found on Amazon.




Things you should know:

(1) The box is currently going through aa redesign.

(2) Box "Base.stl" and "Box Lid.stl" are the 3D box design's for you to download and print. Or you can make your own with something else.

(3) I wrote this in Arduino IDE. I am uncertain if it will work with other IDE's.

(4) The sparkfun Ultrasonic isn't optional. Its the only one that runs with the power that the 3.7V 2000mAh can suply.

(5) In Arduino, you will need to download the "SparkFun_Qwiic_Ultrasonic_Arduino_Library.h" For it to work.



Enjoy.
